# SQL Analytics: The 30-Task Gauntlet

## 1. Overview
This repository contains a comprehensive series of business intelligence challenges solved using SQL. The "Gauntlet" covers three distinct domains: Retail Operations, Aviation Analytics, and Human Resources.

## 2. The Project Goal
The objective is to transform raw transactional data into actionable insights by focusing on three key pillars:
* **The Need:** Identifying the specific business problem.
* **The Query:** Developing optimized SQL logic to extract the data.
* **The Impact:** Explaining how the data drives strategic decision-making.

## 3. Database Roadmap
- **Northwind (Retail):** Queries focused on revenue math, inventory risk, and customer retention.
- **Airlines (Aviation):** Queries covering route optimization, delay logic, and capacity checks.
- **AdventureWorks (HR):** Queries addressing employee audits and organizational structure.

## 4. Tech Stack
- **SQL:** Complex Joins, CTEs, Window Functions, and Aggregate Logic.
- **Quarto:** For professional documentation and report rendering.
- **Git/GitHub:** Version control and project management.
